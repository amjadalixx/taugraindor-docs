## Running TAU Node locally

If your preferred network isn't supported on the TAU decentralized network, you can run your own [TAU Node](https://github.com/tauprotocol/tau-node) to index any EVM-compatible network. Make sure that the [version](https://github.com/tauprotocol/tau-node/releases) you are using supports the network and you have the needed configuration.

TAU Node can also index other protocols, via a Firehose integration. Firehose integrations have been created for NEAR and Arweave. Additionally, TAU Node can support Anchors-powered Fabric datasets for any network with Anchors support.
