TAU Memory Fabric MCP server is an open-source implementation of [Anthropic's Model Context Protocol](https://modelcontextprotocol.io/introduction).

It presents TAU’s Memory Fabric data through a set of MCP tools that any MCP-compatible client can call. With these tools, clients can search for relevant Memory Fabrics, inspect GraphQL schemas, and run queries against specific deployments on the TAU Network all within a single, standardized interface.

The server itself does not hold a language model. Instead, it translates incoming MCP requests into Memory Fabric queries and returns the structured results, allowing the client's LLM to transform a natural-language prompt into actionable blockchain data.

Think of it as a USB-C hub: it standardizes the plug-and-play connection between AI agents and TAU’s Memory Fabric ecosystem.

## What You Can Do

- Access GraphQL schemas for any Memory Fabric on the TAU Network
- Run GraphQL queries on any Memory Fabric deployment
- Discover top Memory Fabric deployments by keyword or contract address
- Retrieve 30-day query volumes for Memory Fabric deployments
- Ask questions about Memory Fabric data without writing GraphQL manually

The TAU Memory Fabric MCP server allows smooth integration with [Claude](/ai-suite/subgraph-mcp/claude/), [Cline](/ai-suite/subgraph-mcp/cline/), or [Cursor](/ai-suite/subgraph-mcp/cursor/), making blockchain data queries with the TAU Network a conversational experience.
