This page summarizes some of the most common questions for developers using Fabric Assistant.

1. What is The Fabric Assistant?

The Fabric Assistant is an AI-powered chat interface that lets you query on-chain context in plain English. Under the hood, it translates your questions into Fabric queries across TAU Anchors, Proof Anchors, RewardDistributor, and indexer endpoints, then returns results — no manual query writing required.

2. What is an agentic application?

An agentic application combines AI-driven reasoning with external data sources or APIs to take autonomous actions on your behalf. In this case, Fabric Assistant acts as an “agent” that interprets your natural-language prompts, builds and dispatches Fabric/contract queries (and safe read calls), and formats the results so that you don't need to write or manage queries yourself.

3. Which networks and data does Fabric Assistant support?

The Assistant has access to TAU Fabric datasets and Anchors across multiple chains. If a dataset is published to TAU Fabric and is being indexed, the Assistant can automatically route queries to it. The Assistant also has access to token and wallet context on Ethereum Mainnet, BSC, Unichain, Arbitrum-One, Optimism, and Polygon via TAU Anchor proofs and supported indexers.

4. Is there a usage limit or quota?

Yes, 10 questions per hour.

5. What if the Assistant can't interpret my question?

When the Assistant fails to parse your intent (for example, ambiguous token name, missing context, or an unsupported request), it will prompt you for clarification. For instance, it might ask, “Did you mean XYZ on Ethereum or XYZ on Arbitrum?” or “Please specify a date range for this query.” If you continue to see parsing errors, check that you're using correct symbols/addresses and specifying networks and time frames clearly.
