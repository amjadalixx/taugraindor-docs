This page summarizes some of the most common questions for developers using TAU AI.

1. What is TAU AI?

TAU AI is an intelligence-powered assistant that lets you interact with the TAU ecosystem in natural language. It translates your questions into queries across Memory Fabric, Trust Index, and Growth Kit, then returns structured insights—no manual coding required.

2. What is an agentic application in TAU?

An agentic application in TAU merges AI-driven reasoning with live blockchain data and APIs to act on your behalf. TAU AI acts as an “agent” that interprets your prompts, constructs data requests, and returns formatted results so you don’t need to handle technical complexity yourself.

3. Which networks and data does TAU AI support?

TAU AI connects to supported chains via Memory Fabric and integrates with the Trust Index and Growth Kit. It supports EVM-compatible chains and more, automatically routing queries to the right data source depending on availability and context.

4. Is there a usage limit or quota?

Yes, 10 queries per hour during the initial rollout phase. Limits will expand as the ecosystem grows.

5. What if TAU AI can’t interpret my question?

If TAU AI cannot resolve your request (for example, ambiguous project name, missing context, or unsupported query), it will ask for clarification. For instance: “Did you mean Project Alpha on Ethereum or on Polygon?” or “Please specify the timeframe.” If errors persist, check that you are using the correct identifiers and providing complete context.
