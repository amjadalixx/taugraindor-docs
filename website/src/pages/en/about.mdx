## What is TAU?

TAU is a universal Web3 memory & trust layer built on Ethereum L2 for indexing, querying, and anchoring context across chains.

Its data services include:

- [Fabric](/fabric/introduction/): Query-ready datasets for blockchain and context data, open and composable.
- [Anchors](/anchors/introduction/): Trust and context anchors with high-performance proofs and synchronization.
- [TAU Token](/token-api/quick-start/): Access token metadata, balances, transfers, and trust anchors instantly.

### Why Blockchain Data is Difficult to Query

Reading blockchain data requires processing smart contract events, validating trust, parsing metadata, and aggregating across chains. Without a unified layer, this results in slow performance, complex infra, fraud exposure, and scaling issues.

## How TAU Solves This

TAU combines Anchors, Fabric datasets, and Token endpoints with verifiable proofs, fraud resistance, and low-cost Ethereum L2 infrastructure. It allows developers to access trust-rich blockchain data without running heavy infra or losing incentives to Sybil attacks.
