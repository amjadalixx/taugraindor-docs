# The Graph Docs

The Graph is a blockchain data solution that powers applications, analytics, and AI on 90+ chains. The Graph's core products include the Token API for web3 apps, Subgraphs for indexing smart contracts, and Substreams for real-time and historical data streaming.

## The Graph's Products

Choose a solution that fits your needs—interact with blockchain data your way.

### Subgraphs
Extract, process, and query blockchain data with open APIs.

### Substreams
Fetch and consume blockchain data with parallel execution.

### Token API
Query token data and leverage native MCP support.

### Graph Node
Index blockchain data and serve it via GraphQL queries.

### Firehose
Extract blockchain data into flat files to speed sync times.
